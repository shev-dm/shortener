# Вариант 8 — Сокращение ссылок

Простой сервис сокращения ссылок из 4 контейнеров:

| Сервис        | Технология        | Описание                                                        |
|---------------|-------------------|-----------------------------------------------------------------|
| `frontend`    | HTML + JS, nginx  | Веб-интерфейс, проксирует `/api` и `/s` на бэкенд               |
| `backend`     | Go                | REST API, работа с БД, редирект по короткой ссылке              |
| `web-service` | Go                | Микросервис генерации короткого алиаса (`POST /shorten`)        |
| `db`          | PostgreSQL        | Таблица соответствий коротких и длинных ссылок                  |

## Запуск

```bash
docker compose up -d --build
```

Открыть http://localhost:8080

- **Показать все ссылки** — таблица из БД: основная ссылка, сокращённая, время создания.
- **Удалить** (в каждой строке таблицы) — удаляет ссылку из БД.
- **Сократить ссылку** — открывает окно, вводим URL, получаем короткую ссылку.

Переход по короткой ссылке `http://localhost:8080/s/<код>` перенаправляет на исходный URL.

## API бэкенда

- `GET /api/links` — список всех ссылок
- `POST /api/shorten` `{"url": "https://..."}` — сократить ссылку
- `DELETE /api/links/{code}` — удалить ссылку
- `GET /s/{code}` — редирект

Остановка: `docker compose down` (с удалением данных БД: `docker compose down -v`).
